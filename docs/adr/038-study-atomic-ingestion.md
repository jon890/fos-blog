# ADR-038: 수집 cursor와 자료, 재시도 영수증을 함께 저장한다

- **status**: `superseded`
- **결정**: 소스와 수집 mode별 cursor를 잠그고 자료·소스 연결·cursor·영수증을 하나의 트랜잭션으로 저장한다.
  같은 멱등 키의 재전송은 버전 검증보다 먼저 기존 영수증을 반환한다.
- **맥락**: career-os는 최근 글과 과거 글을 다른 cursor로 수집한다.
  응답 유실이나 자료 저장 실패 후 cursor만 진행하면 자료가 누락되고, cursor만 되돌리면 중복 요청이 발생한다.
- **대안 기각**:
  - cursor 단독 갱신 API는 자료 저장 성공과 수집 진도 사이에 실패 구간을 만든다.
  - 메모리 멱등 캐시는 재시작과 다중 인스턴스에서 이전 성공 여부를 잃는다.
  - 수집 결과를 비동기 큐에 넣으면 별도 상태 조회와 완료 통지가 필요하다. 현재 배치 제한에서는 동기 저장으로 충분하다.
- **결과**:
  - 얻는 것: 응답 유실 재시도에 같은 영수증을 반환하고 자료 저장 실패 시 cursor도 되돌린다.
  - 감당할 것: DB 잠금과 영수증 보존 비용이 생긴다. 수집기는 배치마다 고정 키를 유지하고 충돌 시 cursor를 다시 읽어야 한다.

이 트랜잭션 계약은 career-os Backend의 저장 계층으로 옮겨갔다.
fos-blog는 더 이상 수집 cursor와 자료, 영수증을 저장하지 않는다.
원자성과 멱등 계약 자체는 그대로 유지하며 그것을 구현하는 저장소만 바뀌었다.
소유권 이전 결정은 [ADR-039](./039-career-study-backend-ownership.md)에 둔다.

키·본문·상태 코드는 [자료 배치 계약](../api/study-library.md#자료-배치-저장)에 둔다.
