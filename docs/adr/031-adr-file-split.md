# ADR-031. 기술 결정을 ADR별 파일로 분리한다

## 맥락과 결정

단일 ADR 문서에 새 결정을 추가할 때 파일 끝과 인덱스에서 병렬 작업의 충돌이 반복됐다.
각 결정을 `docs/adr/NNN-slug.md`에 두고 [분류별 인덱스](README.md)로 연결한다.
번호를 파일명에 유지해 기존 `ADR-NNN` 참조로도 찾을 수 있게 한다.

## 이유와 기각한 대안

- 단일 파일을 유지하면 서로 다른 결정을 추가하는 작업도 같은 위치를 수정하므로 충돌이 반복된다.
- 신규 ADR만 분리하고 기존 문서를 그대로 두면 두 탐색 방식을 함께 관리해야 하므로 기각했다.
- 결정별 파일은 서로 다른 본문의 충돌을 줄이고 관련 결정만 읽을 수 있게 한다.

## 남는 비용

분류별 인덱스는 여전히 공유 파일이므로 같은 분류에 항목을 추가하면 충돌할 수 있다.
본문 분리가 인덱스의 자동 충돌 해소를 보장하지는 않는다.
인덱스 변경은 실제 본문 파일과 링크를 대조해 병합한다.
결번은 재사용하지 않고 인덱스의 보존 정책을 따른다.
