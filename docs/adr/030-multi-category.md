## ADR-030. 경로 카테고리를 유지하며 다중 카테고리를 추가한다

- **결정**
  - 경로의 첫 폴더를 주 카테고리로 유지한다.
  - frontmatter의 `categories`와 주 카테고리를 중복 제거해 `posts.categories`에 저장한다.
  - 카테고리 페이지는 폴더 글과 `JSON_CONTAINS`로 찾은 교차 게시 글을 함께 보여준다.
  - 카드, 상세, 검색 결과에는 전체 카테고리 배지를 표시한다.
- **맥락**
  - 경로는 하위 폴더 탐색을 담당하고 카테고리는 글의 다중 소속을 나타낸다.
  - 둘 중 하나로 통합하면 기존 폴더 탐색이나 다중 소속 표현이 사라진다.
- **기각한 대안**
  - 카테고리 조회로 폴더 탐색을 교체하면 하위 폴더와 깊은 경로 탐색이 깨진다.
  - 관계 테이블은 현재 글 규모에서 동기화와 마이그레이션 복잡도만 늘린다.
- **결과**
  - 카테고리 목록의 글 수와 연관 글 점수는 주 카테고리 기준을 유지한다.
  - JSON 배열 조회는 전체 검색이므로 글 규모가 커지면 다중 값 인덱스나 관계 테이블을 재검토한다.
  - 동기화는 실제 폴더와 정적 메타에 없는 이름을 경고하되 저장은 막지 않는다.
  - 알 수 없는 최상위 폴더는 원래 이름과 이름 기반의 안정적인 색상으로 표시한다.
