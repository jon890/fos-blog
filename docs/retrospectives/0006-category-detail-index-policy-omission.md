# 카테고리 상세 문서에 색인 정책이 누락됨

## 관찰

ADR-036과 task는 얇은 카테고리의 sitemap 제외와 `robots` 정책을 정의했지만,
카테고리 상세 페이지 문서의 SEO 절은 기존 메타데이터 필드만 설명했다.

## 원인

계획에서 ADR 갱신을 문서 수정 완료로 간주하고,
라우트 행동을 설명하는 `docs/pages/category-detail.md`까지 대조하지 않았다.

## 영향

새 `noindex` 분기와 `follow` 차이,
임계값,
공용 판정 함수가 페이지 문서에서 보이지 않아 코드와 문서가 어긋났다.

## 대응

`docs/pages/category-detail.md`의 갱신일과 SEO 절을 수정했다.
빈 카테고리와 얇은 카테고리의 `robots` 차이,
직속 글 계산 기준,
ADR-036 링크를 추가했다.

## 검증

docs-verifier에게 수정한 페이지 문서와 코드를 다시 대조하도록 요청한다.

## 배운 점

라우트의 검색 정책을 바꾸면 ADR만이 아니라 해당 페이지 문서의 SEO 책임도 함께 대조해야 한다.

## 후속

재검증에서 문서 추가 누락이 없으면 이 회고를 현재 상태로 닫는다.

## 재검토 발견

첫 문서 보완은 빈 카테고리와 얇은 카테고리를 나란히 적었지만,
얇음의 수치 조건이 빈 카테고리에도 성립한다는 우선순위를 드러내지 못했다.
실제 코드는 빈 카테고리 분기를 먼저 반환한다.

## 최종 대응

두 조건이 겹치지 않도록 두 번째 문구를 “내용이 있지만 얇은 카테고리”로 구체화했다.
